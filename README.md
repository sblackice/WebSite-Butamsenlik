# Butamsenlik

"Bu tam senlik": altın kaplama takı markası için tek sayfalık web sitesi. Saf HTML, CSS ve JavaScript; kurulum gerekmez.

## Nasıl açılır
`index.html` dosyasını tarayıcıda açın. GitHub Pages ile yayınlamak için: depo **Settings → Pages → Branch** seçip **Save**.

## Yayından önce değiştirilecekler
- `script.js` içindeki `WHATSAPP_NUMBER` (şu an boş; gerçek numara ülke koduyla, örn. `905xxxxxxxxx`).
- `index.html` içindeki Instagram bağlantısı ve `merhaba@butamsenlik.com` e-posta adresi (örnek).
- Ürün adları ve "Hediye paketiyle gönderim" gibi bant yazıları örnektir; gerçek bilgilerle değiştirin.
- Takı görselleri kodla çizilmiş geçici çizimlerdir; gerçek ürün fotoğraflarınızla değiştirilmesi önerilir.

## Dosyalar
- `index.html`, `styles.css`, `script.js`: site
- `docs/BRIEF.md`: konsept, duygu eğrisi, bölüm planı
- `docs/design-dna.json`: referans siteden ölçülen renkler ve yeni yumuşak palet
